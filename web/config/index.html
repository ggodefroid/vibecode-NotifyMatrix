NotifyMatrix — Configuration initiale

Assistant pour le panneau NotifyMatrix (Matrix Portal S3) — Île-de-France, Nantes ou Laval.

Mode configuration panneau — Connectez-vous au Wi‑Fi NotifyMatrix-Setup (mot de passe : notifymatrix), puis ouvrez http://192.168.4.1.

Réseau Wi‑Fi

Connexion du panneau à votre box ou point d'accès local.

Notifications MQTT

Optionnel. Laissez l'hôte vide pour désactiver MQTT. Le panneau s'abonne au topic indiqué.

Accès aux données transports

Une seule clé API suffit pour tout le panneau. Choisissez le réseau par ligne à l’étape suivante.

Île-de-France PRIM

Temps réel via clé PRIM. Arrêts STIF:StopArea:SP:… ou STIF:StopPoint:Q:….

Nantes Open

Temps réel open.tan.fr — sans clé API.

Laval (TUL) GTFS

Horaires théoriques (data.gouv). Mise à jour auto du zip (~48 h).

Obligatoire si au moins une ligne est en Île-de-France. Inutile pour Nantes et Laval (GTFS).

Exemple bus P vers Paris Est : filtre Paris Est + arrêt STIF:StopArea:SP:68494: (code arrêt PRIM 68494).

Laval (TUL) — arrêts GTFS

Le panneau télécharge le fichier GTFS officiel TUL (~1,4 Mo) et calcule les horaires théoriques pour l’arrêt et la ligne choisis. Identifiants dans stops.txt du zip (data.gouv).

  • Stop ID : ex. lavgsnc0 (Gare SNCF), lavgtul3 (11 novembre – Gare TUL).
  • Ligne : route_short_name GTFS (ex. A, 12, H) — pas les codes IDFM C0….
  • La première requête peut prendre ~30 s (analyse du GTFS) ; les suivantes utilisent le cache du panneau.

Cochez « Horaire HH:MM » pour afficher l’heure prévue plutôt que les minutes d’attente.

Lignes affichées

Une ligne fixe ou un carrousel (jusqu’à 16). Chaque entrée choisit son réseau — IDFM, Nantes ou Laval.

Une seule ligne

Affichage fixe d'un arrêt et d'une ligne.

Carrousel

Rotation automatique entre plusieurs lignes (max. 16).

Affichage panneau

Texte affiché en mode configuration (setup), couleurs de l'horloge et des temps d'attente, et mode QUAI / PCH / minutes.

Splash au démarrage

Animation arc-en-ciel affichée à chaque allumage du panneau (texte centré, ex. TweakFR). Laissez le texte vide pour n'afficher que les couleurs.

Mettez 0 ms pour désactiver l'animation au démarrage.

Écran mode configuration Wi‑Fi

Texte affiché quand le panneau est en point d'accès setup. Laissez vide pour les valeurs par défaut (SSID AP, mot de passe, IP).

Luminosité

Valeurs de 0 (éteint) à 255 (maximum). Le mode nuit s'applique entre l'heure de début et l'heure de fin (ex. 20h → 7h = soir et nuit plus faible).

Horloge (zone gauche)

Zone bus — couleurs et seuils (minutes)

Le temps affiché change de couleur selon les minutes restantes : vert si > seuil vert, orange si ≥ seuil orange (et ≤ seuil vert), rouge en dessous du seuil orange. Pas d'info pour --.

Clignotement QUAI / PCH

Quand le texte affiché est le libellé court ou moyen (ex. QUAI, PCH), il alterne entre deux couleurs — par défaut blanc puis rouge toutes les ~300 ms. Pas de clignotement sur les horaires HH:MM ni sur Nm si vous cochez « afficher le temps » ci-dessous.

Carrousel et ligne

Texte d'attente (bus)

Exemple auto : ≤1 min → QUAI (clignote blanc/rouge), ≤3 min → PCH (idem), au-delà → 5m, 12m… Libellés personnalisables (5 car. max). Le clignotement couleur ne s'applique qu'aux libellés, pas aux minutes affichées.

Générer le fichier .env

Copiez ce contenu dans un fichier nommé .env à la racine du projet, puis compilez.

Étapes suivantes
  1. Enregistrez le fichier téléchargé sous Panneau IDFM V5/.env
  2. Dans un terminal : pio run -e matrixportal_s3 -t upload
  3. Surveillez la sortie série : pio device monitor -b 115200

Le fichier .env contient des secrets : ne le partagez pas et ne le commitez pas (déjà dans .gitignore).
